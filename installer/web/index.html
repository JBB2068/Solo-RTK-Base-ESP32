Solo RTK Base

ESP32-C3 firmware that sends RTK corrections to a 3DR Solo over SoloLink. Version …

Install

  1. Use Chrome or Edge on a computer (Windows, Mac, Linux or ChromeOS).
  2. Plug the ESP32-C3 into a USB port with a data cable.
  3. Click Install, pick the port (it shows as USB JTAG/serial debug unit), and confirm.
This browser can't flash devices. Open this page in Chrome or Edge on a computer. Open this page over https.

On a first install, let it erase the device. When updating, choose not to erase and your settings stay.

After installing

  1. Join the Wi-Fi network SoloRTK-XXXX, password solortk1.
  2. Open http://192.168.4.1, enter your SoloLink network name and password, and press Save & reboot.
  3. Connect the base GPS: GPS TX → GPIO20, GPS RX → GPIO21, GND → GND, 115200 baud, RTCM3 output.
  4. Set ArduPilot GPS_INJECT_TO = 127.

If the port doesn't show up or the install fails: hold the BOOT button while plugging in, then try again.

No Chrome? Download the Windows or Mac/Linux package from the latest release.
